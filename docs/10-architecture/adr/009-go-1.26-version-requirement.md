# ADR-009: Rejected Go 1.26+ Consumer Requirement

**Date**: 2026-08-25
**Status**: Rejected
**Deciders**: Repository owner (the original raise had no recorded explicit
approval; the rejection and reaffirmation of ADR-004 were approved on 2026-08-25)
**Does not supersede**: [ADR-004](004-go-version-requirement.md)
**Related**: ADR-006 (No CGO Dependencies)

## Context

The original proposal would have raised the consumer baseline from Go 1.24 to
Go 1.26 without recorded explicit approval. The subsequent decision rejects
that raise and reaffirms ADR-004; successful Go 1.24.11 build, test, and vet
evidence exists for the current module.

## Decision

Rejected. ADR-004 remains the accepted contract: the module supports Go 1.24.0
or newer. Development and regular CI use Go 1.26.7 as the recommended pinned
toolchain without changing the consumer minimum.

- `go.mod` declares `go 1.24.0` and `toolchain go1.26.7`.
- Regular CI runs with Go 1.26.7; a local, read-only Go 1.24.11 job verifies
  the consumer baseline.
- Raising the minimum minor Go version requires an approved replacement ADR,
  explicit compatibility evidence, and aligned documentation.

## Consequences

- Source builds and module consumers continue to need Go 1.24 or newer.
- The repository must preserve Go 1.24 compatibility while developing and
  testing with the newer recommended toolchain.
- Pure-Go and no-CGO constraints from ADR-006 remain unchanged.

## Verification

Release readiness requires all of the following:

- the declared toolchain is available from the official Go distribution;
- module download and verification leave `go.mod` and `go.sum` unchanged;
- build, test, vet, vulnerability, and repository validation gates pass with the
  pinned Go 1.26 patch release and with the local Go 1.24.11 compatibility job;
- public documentation consistently states the Go 1.24.0 consumer minimum.
